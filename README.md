# BBMB 1200 — Brew Blitz

A neon arcade quiz on yeast and fermentation, built from the Chemistry of Beer lectures.
50 questions across five subjects (choose a stage), shuffled answer choices, timed scoring
with combos, and a brewery rank at the end.

Open `index.html` in a browser, or via GitHub Pages at `https://swnisu1.github.io/BBMB_1200/`.
