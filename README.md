# BBMB 1200 — Brewing Science Review

An interactive 50-question self-check across five topics from the Chemistry of Beer lectures
(yeast & microbes, sugars & fermentation, oxygen/lipids/esters, sulfur & water, GMOs & engineering).
Pick a subject area or take a mixed set; every answer comes with an explanation.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → deploy from `main`)
for a shareable link: `https://swnisu1.github.io/BBMB_1200/`.
